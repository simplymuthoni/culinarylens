# Culinary Lens

This is a Next.js application that allows you to upload a photo of a meal and get a recipe for it, generated by AI.

## How it works

1.  **Upload a photo:** Use the upload form on the homepage to select or drag and drop an image of a dish.
2.  **AI Analysis:** The application uses Google's Gemini AI model to identify the dish in the photo.
3.  **Recipe Generation:** Once the dish is identified, the AI generates a detailed recipe, including ingredients and step-by-step instructions.
4.  **Image Generation:** The app also generates a new, appetizing image of the dish using an AI image generation model.

## Tech Stack

-   **Framework:** [Next.js](https://nextjs.org/) (with App Router)
-   **AI:** [Google AI Gemini & Imagen](https://ai.google/) via [Genkit](https://firebase.google.com/docs/genkit)
-   **UI:** [React](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), [Tailwind CSS](https://tailwindcss.com/)
-   **Components:** [shadcn/ui](https://ui.shadcn.com/)
-   **Styling:** [Tailwind CSS](https://tailwindcss.com/)

To get started with the app, run `npm run dev` and open `http://localhost:9002` in your browser.
